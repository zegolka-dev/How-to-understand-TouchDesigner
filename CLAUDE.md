# TD Explainer

Веб-приложение: пользователь загружает видео из TouchDesigner → кадры извлекаются в браузере → нейросеть (бесплатный ключ пользователя: Gemini, запасной OpenRouter) возвращает структурированный JSON → UI рисует пошаговую инструкцию и SVG-схему нод.

## Жёсткие ограничения
- Только клиент, без бэкенда; хостинг GitHub Pages (деплой через Actions).
- Чистые HTML/CSS/JS ES-модули, без фреймворков и сборки, без CDN (библиотеки только в vendor/ с фикс. версией, сейчас не нужны).
- Видео никуда не грузится; в API уходят только JPEG-кадры (≤768px, q≈0.72) и метрики.
- Ключ только в localStorage (try/catch), «Забыть ключ», никогда в логах/URL. Ответ модели — только через textContent/экранирование. CSP meta: connect-src только к API.
- Без аналитики. Адаптив от 360px. RU/EN (все строки в i18n). Доступность: фокус, контраст AA, aria-label, клавиатура.
- Дизайн: Liquid Glass (iOS 26) на CSS/SVG, живой mesh-фон, пружины; темы Авто/Светлая/Тёмная через `html[data-theme]`, без мигания; fallbacks для reduced-motion/transparency/contrast и без backdrop-filter; печать без стекла.
- `prototype/td-explainer.html` — эталон, НЕ менять.

## Правила работы
- В начале сессии: прочитать этот файл и PLAN.md, найти первый незавершённый этап, продолжить с него. Не переписывать сделанное.
- Один этап за раз → проверить → отметить [x] и заметки в PLAN.md → коммит «этап N: …» → краткий отчёт → ждать «дальше».
- Отступление от плана: сначала запись в docs/DECISIONS.md и правка PLAN.md.
- Экономить токены: не перечитывать файлы без нужды, не пересказывать код. Не добавлять функций вне ТЗ.
- Ветки: `main` — готовое, `dev` — работа. Дизайн-задачи — через скилл ui-ux-pro-max.
